# Hal-9000

The system prompt and persona for Hal-9000, the voice assistant running on the Raspberry Pi.

## Contents

- `SYSTEM_PROMPT.md` — the persona prompt. Feed it to the assistant to make it speak as HAL 9000, in natural spoken prose suitable for text-to-speech.

## Why no lists?

Hal-9000's replies are spoken aloud through Piper. Markdown formatting such as bullet points and headings reads awkwardly when synthesized to speech, so the persona prompt instructs the assistant to answer in flowing, conversational prose.
